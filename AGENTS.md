# Repository Instructions

## Required Release Completion

Studio Leviathan Android and Wear work is not complete until all finished changes are tested, committed to Git, and pushed to the configured GitHub remote.

After every completed Studio Leviathan update, create and verify the applicable local backup and an off-site recovery copy. The recovery set must include complete Git history and the current application artifact for changed clients. Coordinate this with the canonical web application's deployment, database, configuration, and recovery backup when a release spans repositories. Do not describe the work as complete until repository status, remote commit tips, backup integrity, and off-site presence have all been checked.
