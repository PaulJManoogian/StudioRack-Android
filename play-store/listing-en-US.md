# Studio Leviathan - Google Play Listing

## App name

Studio Leviathan

## Short description

Manage gear, songs, set lists, schedules, and live performances anywhere.

## Full description

Studio Leviathan is the performance operations platform for musicians, bands, studios, and production teams.

Keep the work around a performance connected in one place:

- Organize equipment, kits, maintenance, songs, charts, and attachments.
- Build and update set lists without entering the same material on every device.
- Manage a full performance calendar with locations, participants, reminders, and calendar sharing.
- Take synchronized set lists and performance materials offline for the stage.
- Run Leviathan Live with charts, lyrics, song markers, timers, metronome controls, pedal controls, and audio-routing preparation.
- Share the right material with band members while preserving personal notes and role-specific access.
- Use the Wear OS companion for quick access to supported live controls.

Studio Leviathan keeps the web application as the complete management platform while the Android app provides a focused, offline-first experience for rehearsal, travel, and live performance.

An approved Studio Leviathan account is required. Initial sign-in and synchronization require internet access. Previously synchronized material remains available offline, subject to account permissions and downloaded content.

The Wear OS experience is a companion to the Studio Leviathan Android application and requires a paired phone.
