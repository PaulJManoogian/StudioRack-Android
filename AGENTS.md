# Repository Instructions

## Required Release Completion

Studio Leviathan Android and Wear work is not complete until all finished changes are tested, committed to Git, and pushed to the configured GitHub remote.

After every completed Studio Leviathan update, verify Git history, the pushed remote tip, and the current application artifact for changed clients. Coordinate release verification with the canonical web application when work spans repositories. A full local and off-site recovery set is created every 15 major completed updates, or immediately when the product owner explicitly requests one or a release changes recovery-critical infrastructure. Do not reset this cadence for ordinary code updates.
