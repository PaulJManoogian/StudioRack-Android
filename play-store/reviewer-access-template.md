# App Access Instructions

Studio Leviathan requires an approved account and multi-factor sign-in. Create a dedicated non-admin reviewer account with representative songs, a set list, an event, equipment, and one downloadable performance attachment.

Enter these values in **Play Console > Policy and programs > App content > App access**:

- Account email: `[REVIEWER EMAIL]`
- Temporary access code: `[REVIEWER ACCESS CODE]`
- MFA or recovery instructions: `[EXACT REVIEWER STEPS]`

Suggested reviewer note:

> Sign in with the supplied Studio Leviathan reviewer account. Follow the on-screen verification step using the supplied recovery instructions. The account contains sample equipment, songs, set lists, a scheduled event, and Leviathan Live materials. Administrative platform controls are intentionally not part of the Android application. The Wear OS application is a companion and requires the Android phone application.

Before every submission, verify the credentials on a clean device and keep them valid for the entire review period.
